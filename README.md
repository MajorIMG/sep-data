# sep-data

Public list of current Medicare disaster special enrollment periods (DST SEPs), refreshed weekly from carrier notices. The file dst.json lists each declaration: state, declaration type, areas, incident dates, and the date applications are accepted through (sep_end). Entries drop off after their end date.

Public information only. Never add client, agent or NPN data here. Carrier lists are not complete, so always confirm eligibility and dates with the carrier before submitting.
